## 新增配置和迁移

- **数据库迁移**：只有 `0008_avoid_artists`（给 `user_preferences` 加一列带默认值，纯加法，不需要停机；回退不用降级迁移，旧代码不读这一列）。`0005`–`0007` 已经在 main 上。
- **新增环境变量**（都有默认值，不设也能跑）：
  - `WAVECAST_CATALOG_POOL`（默认开）：泛请求候选池。关掉会让泛请求只出 13 分钟左右。
  - `WAVECAST_DURATION_SCALING`（默认开）：时长分级。
  - `WAVECAST_TRACK_RESEARCH`（默认开）：按曲目找资料。出问题时可单独关。
  - `LASTFM_API_KEY`（可选）、`WAVECAST_LOG_LEVEL`（默认 INFO）。
  - 事实核对**没有开关**。
- **额度上限**（已有，发布时核对数值）：游客 3 档、登录用户每天 20 档、全站每天 100 档；首页推荐每人每天最多真实生成 4 次。
- **费用**：DeepSeek 用量记录已带缓存命中统计；首页推荐和详情页不新增每次浏览的模型调用。

1. **先发后端（Railway），再发 Web（Vercel）。** 新后端只加字段和接口，旧 Web 兼容；反过来 Web 先上会打到没有 `/public`、`/adopt`、`/by-code`、`/recommendations/me/next` 的旧后端。
2. 发布前确认 Railway 的来源分支和 SHA（不要假设它还跟踪某个分支）；确认 `0008` 会在启动时执行。
3. 回退：Railway 重新部署上一个部署即可，数据库那一列保留不影响旧代码；Web 回退用 Vercel 的上一个生产部署。

## 发布后在生产验收（用户在 wavecast.space 上做）

- 游客首页：精选卡片显示新的展示标题，点卡片先出详情面板，点播放才开始生成。
- 登录后首页：推荐 4 档、标题和封面短标题正常、没有空白封面（新生成的）；点“换一批”能换；今天能换的都换过后有提示。
- 自己调一档节目：能开播，标题不是“A：B”形式，不出现编造的情境。
- 节目库：点整行进详情页，右边环形按钮直接续播；详情页的按钮随进度变化（继续播放、再听一次、回到播放页）。
- 分享：复制短链接 `/p/…`，用另一个浏览器（游客）打开，看到简介，点播放得到自己的一份；链接失效页正常；把链接发进聊天软件，预览有标题、简介和图。
- 少放这类：播放页点一次，账号页“少放的歌手”里出现该歌手，可以取消；之后的推荐不再围绕他。
- 额度：游客用完额度时，详情页显示登录按钮。
- 费用：当天看一次 DeepSeek 用量，确认没有意外飙升。
