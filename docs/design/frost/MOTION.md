# WaveCast 动效与手势规范

> 配合 `HANDOFF.md` 使用。目标：让 PWA 的手感接近原生 App。所有动效使用同一套时长、曲线和手势阈值，不要每个组件各写一套。

## 1. 原则

1. **跟手**：拖拽类交互 1:1 跟随手指，没有延迟。
2. **可打断**：动画进行中用户可以随时抓住元素，从当前位置继续，不能等动画播完。
3. **有方向**：东西从哪来就回到哪去。抽屉从底部来，就向底部收；播放页从迷你条展开，就收回迷你条。
4. **只动 transform 和 opacity**：不要对 top、height、width、filter 做动画（模糊背景不要做动画）。拖拽期间加 `will-change: transform`，结束后去掉。
5. **不用 setInterval 做动画**：连续动画一律用 `requestAnimationFrame`，按真实经过时间计算，而不是按帧数。
6. **减少动态效果**：`prefers-reduced-motion: reduce` 时，所有位移、缩放、摆动改为 150ms 的淡入淡出；氛围动画（波形、噪点、光晕变化）直接显示最终静态状态。

## 2. 时长与曲线

```css
:root {
  --dur-instant: 100ms;  /* 按压反馈 */
  --dur-fast: 150ms;     /* 图标切换、文字交叉淡化 */
  --dur-base: 250ms;     /* 组件状态切换、遮罩 */
  --dur-slow: 350ms;     /* 抽屉、弹窗进出 */
  --dur-page: 400ms;     /* 播放页展开收起 */

  --ease-standard: cubic-bezier(.2, .8, .2, 1);   /* 默认 */
  --ease-enter: cubic-bezier(.05, .7, .1, 1);     /* 进入：快速出现、缓慢停住 */
  --ease-exit: cubic-bezier(.3, 0, .8, .15);      /* 离开：慢慢起步、快速离开 */
}
```

**弹簧**：松手后的回位、吸附用一个小的弹簧函数（自己写，十几行），参数：刚度 380、阻尼 36、质量 1。效果是几乎没有过冲、约 350–400ms 停稳。弹簧要接收松手时的速度作为初速度，这样快速一甩和慢慢松手的手感不同。

## 3. 通用手势

- 用 Pointer Events 加 `setPointerCapture`。可拖动区域设置 `touch-action: none`（只有可拖动的把手区域，不要整页设置）。
- **下拉关闭**（播放页、所有底部抽屉）：
  - 松手时，下拉距离超过自身高度的 25%，**或者**向下速度超过 0.5 px/ms，就关闭；否则弹簧回位。
  - 往上拖（超出打开位置）时加阻尼：`offset = limit * (1 - 1 / (dy * 0.55 / limit + 1))`，`limit` 取 80px。
  - 拖动过程中，背景遮罩的透明度随下拉距离线性降低。
  - 抽屉内容可以滚动时，只有内容滚动到最顶部（`scrollTop === 0`）后继续下拉，才转为拖动抽屉。
- **速度计算**：取最近 80ms 内的指针位移除以时间，不要只用最后两帧。

## 4. 逐项规范

### 4.1 播放页的展开与收起

- **展开**（点击或上滑迷你条）：播放页从底部滑入，400ms，`--ease-enter`。封面从迷你条的缩略图位置放大到播放页的封面位置（共享元素过渡）。优先用 View Transitions API；不支持时手动做 FLIP：记录起止位置，用 transform 补间。下层页面同时加一层 0 → 0.3 的黑色遮罩。
- **收起**：反向过程，封面缩回迷你条。
- **拖动把手**：顶部整块 44px 高的区域都是拖动区，不只是那根小横线。小横线改为 36×5、白色 55% 透明，放在磨砂渐变**之上**，保证能看清。手指按在封面上往下拖也可以收起（按在按钮、进度条、状态条上则不行）。
- 下拉时整个播放页跟手下移，满足第 3 节的阈值就收回迷你条，否则弹簧回位。

### 4.2 底部抽屉（节目路线、主持词全文、更多操作、首次偏好）

- 进入：从 `translateY(100%)` 到 0，350ms，`--ease-enter`；遮罩透明度 0 → 1，250ms。
- 离开：250ms，`--ease-exit`。
- 都支持下拉关闭（第 3 节）。
- 打开时把焦点移到抽屉标题，关闭时把焦点还给触发按钮。

### 4.3 居中弹窗（添加到主屏幕）

- 进入：从 `scale(.96)`、透明度 0 到正常，250ms，`--ease-enter`。
- 离开：150ms 淡出。

### 4.4 页面切换

- 底部导航切换标签：只做 150ms 交叉淡化，不滑动（iOS 的标签切换就是没有滑动的）。
- 迷你条、底部导航在切页时**完全不动**。

### 4.5 迷你播放条

- 只在“开始播放一档新节目”时入场一次：`translateY(16px)` + 透明 → 原位，300ms，`--ease-enter`。之后切页面、切标签都不再播放入场动画。
- 底边进度线随播放连续前进（宽度用 `transform: scaleX()`，不是改 width）。
- 播放/暂停图标切换见 4.6。

### 4.6 按钮与图标

- 按下：`scale(.96)`，100ms；松开回到 1，150ms。只对可点击的元素生效。
- 播放/暂停：两个图标交叉淡化，同时旧图标缩到 .8、新图标从 .8 放到 1，150ms。
- 分段控件：白色滑块在选项间平移，250ms，`--ease-standard`，不是直接跳过去。

### 4.7 调谐窗

- 刻度整体放在一个层上，拖动时只改这一层的 `translateX`，**不要**每一帧重新生成 SVG 路径。窗口外的刻度预先画好一段足够长的范围（87.5–108 全量画一次即可）。
- 拖动 1:1 跟手。松手后先按速度做惯性滑行（速度每毫秒衰减为原来的 0.998 倍，类似 iOS 普通滚动），速度降到 0.05 px/ms 以下时，用弹簧吸附到最近的电台。
- 拨轮纹路随拖动同步移动（改变纹路的相位），看起来像真的在转。
- 台名切换：交叉淡化 150ms。信号格变化：每格依次点亮或熄灭，总共 250ms。光晕颜色：600ms 平滑过渡。
- 噪点层的透明度跟当前频率到最近电台的距离挂钩，距离越远越明显，连续变化，不要只有“有”和“没有”两档。
- 自由输入匹配到电台、或点击首页电台卡片进入时：刻度从当前位置滑到目标电台，500ms，`--ease-standard`。

### 4.8 开播中

- **指针摆动**：进入时指针在目标频率两侧做衰减摆动后停住：`偏移(t) = A · e^(-t/τ) · sin(2πt / T)`，A = 1.2 MHz 对应的像素，τ = 250ms，T = 300ms，900ms 后归零。
- **波形**（现在像定格动画，要重做）：
  - 用 `requestAnimationFrame` 持续绘制，canvas 或单个 SVG path 都可以。
  - **不要每帧生成新的随机数**。杂音部分用随时间平滑变化的噪声：例如三到四个频率不同的正弦波叠加，每个正弦的相位随时间缓慢推进；或者用一维 value noise 在时间上做插值。相邻两帧之间应该只有很小的差别。
  - 正弦部分的相位每秒推进约 2π × 0.8，让波形看起来在流动。
  - “干净程度”是一个 0 到 1 的值，随准备步骤推进（例如 0 → 0.4 → 0.75 → 1），每帧向目标值缓动（每帧靠近 6% 左右），不要跳变。杂音振幅乘以 (1 − 干净程度)，正弦振幅乘以干净程度。
- **步骤点亮**：完成一步时，对勾从 `scale(.6)` + 透明到正常，200ms；下一步的圆点开始缓慢呼吸（透明度 .5 ↔ 1，1.2s 一个周期）。
- 第一段音频可播时，交叉淡化到播放页，350ms。

### 4.9 播放状态条与字幕

- 三种状态之间交叉淡化，250ms，外框不动（已实现，保持）。
- 字幕切句：内容层 `translateY` 平移，300ms，`--ease-standard`。

### 4.10 节目库左滑删除

- 跟手左滑。松手时露出超过 40px 就吸附到露出删除按钮（84px）；否则回位。
- 滑过行宽的 60% 直接删除：该行向左滑出，然后行高收起 250ms，下面的行跟着上移。
- 同一时间只能有一行处于展开状态，点击其他地方收起。

### 4.11 进度条

- 拖动超过“已准备”位置时，滑块按第 3 节的阻尼公式超出一点点，松手弹回已准备位置，同时在进度条上方淡入一行小字“这部分还在准备”，1.5 秒后淡出。

## 5. 验收

- [ ] 中端安卓机和 iPhone 上，所有拖拽和过渡保持流畅（用浏览器性能面板检查，不应出现长任务和明显掉帧）。
- [ ] 播放页、所有抽屉都能下拉关闭，快速一甩也能关，拖一点点松手会弹回。
- [ ] 动画进行中可以抓住元素反向拖动。
- [ ] 切换页面时迷你条和底部导航不动。
- [ ] 开播中的波形连续流动，没有一跳一跳的感觉。
- [ ] 开启“减少动态效果”后没有位移和摆动。
- [ ] 弹簧、速度计算、阻尼公式写成独立的小函数，并有单元测试。
