# WaveCast UI P0 交接文档（雾面方向）

> 给实现者（Claude Code）的说明。设计已和产品负责人确认定稿。本文件和同目录下的设计源文件是唯一依据。

## 0. 一句话

用 Apple 式的克制（纯色、磨砂、系统字体、熟悉的控件）重做 `apps/web` 的界面，只保留一个“收音机”符号：**横向调谐窗**（固定指针 + 滑动刻度）。同时修掉现版本的已知问题（见第 11 节），播放运行时逻辑保持不变。

## 1. 背景与范围

- 阶段：Listening P0 已完成，现在是 UI P0，之后是初赛提交。目标是**一天内做出一版明显好于现版本的前端并部署**，不追求完美。
- 产品定位：轻主持的电台。以音乐为主，主持偶尔说两句。
- 电台（station）：产品上定义了 5 个“电台”，代表 5 种节目做法，话题由用户输入。P0 只在前端体现，后端接入是 P1（第 9 节）。

**本次范围（P0）**

1. 全局外框、设计变量、PWA 基础（manifest、图标）
2. 调频页（含“已对准”“两个台之间”两种状态）
3. 开播中
4. 播放页
5. 节目路线抽屉
6. 迷你播放条
7. 首页
8. 节目库
9. 首次偏好选择
10. 添加到主屏幕引导
11. 程序化封面生成器、App 图标

**不在本次范围**：后端电台改造（P1）、AI 生成文案的优化、深色模式（预留变量即可）、桌面端专门布局（≥980px 时把手机布局居中，最大宽度 430px 即可）。

## 2. 硬性约束

1. **不重写播放运行时。** `components/episode-player.tsx` 里的 HLS、带退避的重试、心跳、进度存档、导出 MP3、后台准备开关等逻辑，行为必须保持不变。做法：先把这些逻辑原样抽成一个 hook（例如 `useProgrammePlayback`），确认现有测试通过、线上行为不变，再让新界面只消费这个 hook。
2. **P0 不改后端接口契约。** 需要但接口里没有的数据，按第 8 节的降级方案处理，并在 PR 里列出核实结果。
3. 遵守仓库根目录的 `AGENTS.md` 和 `docs/PROJECT_STATE.md`。mock 模式必须能完整跑通。
4. `pnpm` 的 lint、typecheck、vitest 全部通过。新增的关键纯逻辑要写单元测试：刻度换算与吸附、封面字号计算、节目库去重、安装引导的出现条件。
5. 不引入大型 UI 组件库或动画库。继续用 CSS（可以把 `app/styles.css` 拆成变量文件和按组件的 CSS 模块）。
6. 每一步一个 commit，完成后开 PR 到 `integration`，用 Vercel 预览验收。

- `<x-dc>` 里是界面标记，样式全部内联。

## 4. 设计规范

### 4.1 颜色

```css
:root {
  --bg: #F2F2F4;            /* 页面底色 */
  --surface: #FFFFFF;       /* 列表组、卡片实色 */
  --ink: #1D1D1F;           /* 主文字、主按钮 */
  --ink-2: #6E6E73;         /* 次要文字 */
  --ink-3: #8E8E93;         /* 辅助文字、未选中的导航 */
  --separator: rgba(60, 60, 67, 0.18);
  --fill: rgba(118, 118, 128, 0.12);   /* 分段控件底、输入框底 */
  --live: #FF6B2C;          /* 直播橙 */
  --danger: #FF3B30;
}
```

**颜色角色规则（最重要的一条）**

- 界面绝大部分只用中性色。
- 电台色只出现在：电台标识点、首页电台卡片、背景光晕、封面。
- 直播橙只表示“正在播出”：调谐窗指针、台标胶囊上的小点、开播按钮里的指示灯、正在播的曲目律动条、迷你条里的小点。不要拿它做普通强调色。

**电台**

| 电台 | 频率 | 浅色（标识点、光晕） | 深色（卡片底，白字） | 一句话 |
|---|---|---|---|---|
| 随便听 | 88.7 | `#E8834A` | `#B5562A` | 音乐为主，偶尔说两句 |
| 唱片行 | 93.1 | `#3E9C8C` | `#2E7D70` | 挖你没听过的 |
| 人物志 | 97.4 | `#C9A04A` | `#8F6B25` | 一位歌手的路 |
| 来龙去脉 | 101.5 | `#5C7CE0` | `#3F5FC4` | 一种风格的来历 |
| 夜里 | 105.8 | `#6E62B6` | `#5A4FA0` | 几乎不说话 |

调频页上的完整描述：

- 随便听：以音乐为主，主持偶尔说两句。像开车时听的电台。
- 唱片行：从一首你喜欢的歌出发，往外挖你还没听过的。
- 人物志：用一位歌手的作品，讲他走过的路。
- 来龙去脉：一种风格是怎么来的，跨年代串起来听。
- 夜里：几乎不说话，节奏放缓。适合睡前和专注。

电台定义放在一个前端常量模块里（例如 `lib/stations.ts`），P1 改为从后端获取。

### 4.2 字体

- 不加载网页字体。界面用系统字体：`-apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 封面里的宋体标题用：`"Songti SC", "Noto Serif SC", "Source Han Serif SC", serif`。
- 所有数字时间、频率用 `font-variant-numeric: tabular-nums`。

| 用途 | 字号/字重 |
|---|---|
| 页面大标题 | 34 / 700 |
| 区块标题 | 22 / 700 |
| 台名、歌名 | 20–22 / 600 |
| 正文、输入框 | 17 / 400（输入框不得小于 16，防止 iOS 放大） |
| 次要文字 | 15 |
| 辅助文字 | 13 |
| 最小（只用于底部导航标签） | 11 |
| 频率大字 | 56 / 200 |

界面上不要再出现 9–10px 的字。

### 4.3 间距与圆角

- 页面左右边距 20px，间距用 4 的倍数。
- 圆角：调谐卡片 28；电台卡片 20；列表组、迷你条 18；调谐窗 18；输入框 16；封面、分段控件外框 12；分段内的选项 9；胶囊按钮 999。
- 所有可点击区域不小于 44×44。

### 4.4 材质

浮在内容上方的元素用磨砂，其余用实色。

| 元素 | 配方 |
|---|---|
| 调谐卡片（浅色） | `background: rgba(255,255,255,.62); backdrop-filter: blur(30px); border: .5px solid rgba(255,255,255,.8); box-shadow: 0 10px 30px rgba(29,29,31,.06)` |
| 底部导航 | `rgba(242,242,244,.78)` + `blur(24px)` + 顶部 .5px 分隔线 |
| 迷你条 | `rgba(250,250,252,.8)` + `blur(30px)` + `0 10px 30px rgba(29,29,31,.14)` |
| 播放页上的元素 | `rgba(255,255,255,.13–.14)` + `blur(24px)` |
| 节目路线抽屉（暗） | `rgba(40,34,26,.72)` + `blur(40px) saturate(1.4)` |
| 浅色抽屉 | `rgba(246,246,248,.94)` + `blur(40px)` |

降级：`@supports not (backdrop-filter: blur(1px))` 以及 `prefers-reduced-transparency: reduce` 时，把背景不透明度提到 0.94 以上，去掉模糊。

**背景光晕**：直径 400–520px 的圆，`filter: blur(80px)`，不透明度 0.14–0.38，颜色是当前电台的浅色。只用在调频、开播中、首页。

### 4.5 动效

- 时长：微交互 150ms，组件状态切换 250ms，抽屉和页面 350ms。
- 缓动：`cubic-bezier(.2, .8, .2, 1)`。
- `prefers-reduced-motion: reduce` 时只保留淡入淡出，去掉位移、缩放、指针摆动。

具体动效：

| 场景 | 动效 |
|---|---|
| 调谐 | 刻度跟手移动；松手后惯性滑动，再吸附到最近电台（300ms ease-out）；信号格、台名、光晕颜色在 250ms 内过渡 |
| 自动匹配电台 | 指针所在刻度平滑滑到匹配的电台（500ms） |
| 开播中 | 指针在目标频率两侧做衰减摆动 2–3 次后停住（约 800ms）；波形随准备步骤从杂音变成平滑正弦波 |
| 开播中 → 播放页 | 第一段音频可播时交叉淡化（350ms） |
| 播放/暂停 | 图标形变 150ms |
| 主持字幕条 | 展开并淡入 250ms；旁白结束后 1.5 秒收起 |
| 迷你条 ↔ 播放页 | 封面共享元素过渡，优先用 View Transitions API；不支持时用淡入加上滑 350ms |
| 抽屉 | 从底部滑入；可下拉关闭，超过阈值回弹 |
| 节目库左滑 | 跟手，超过 40px 吸附到露出删除按钮 |

### 4.6 图标

线性图标，24 网格，描边 1.7–1.8，圆角端点。底部导航三个图标的路径直接用设计稿里的，其中“调频”是调谐窗造型（圆角矩形加一根竖线）。

## 5. App 外框与 PWA

- `html, body { height: 100%; overflow: hidden; overscroll-behavior: none; }`。外框高度 `100dvh`。只有内容区域允许纵向滚动（`overflow-y: auto; overscroll-behavior: contain`）。**播放页、调频页、开播中不滚动。**
- viewport 加上 `viewport-fit=cover`，用 `env(safe-area-inset-*)` 处理刘海和底部横条。
- 控件加 `touch-action: manipulation`；输入框字号不小于 16。
- 新增 `app/manifest.ts`：`name` 和 `short_name` 都是 WaveCast，`display: "standalone"`，`start_url: "/"`，`background_color` 和 `theme_color` 用 `#F2F2F4`，图标 192、512（`any` 和 `maskable` 各一套）。另加 180 的 `apple-touch-icon` 和 favicon。
- 图标由 `LogoMark.dc.html` 的 `radio` 版本导出（这是一个 SVG，可以写个小脚本渲染成 PNG）。maskable 版本要把内容缩到中心 80% 的安全区。
- 现状：`apps/web` 里没有 manifest，也没有 `public/` 图标目录，所以现在其实装不上。
- 按当前 Chrome 的安装条件核实是否需要 service worker。如需要，加一个最小的，**不要缓存音频流和 API**。

## 6. 逐屏说明

### 6.1 调频（`Frost-Tune.dc.html`）

**结构（从上到下）**：大标题“调频” → 调谐卡片（频率大字和信号格 → 台名、“按描述对准”标签 → 一句话描述 → 调谐窗 → 拨轮）→ 输入框 → 时长分段 → 开播按钮 → 底部导航。背景有当前电台色的光晕。

**调谐窗参数**

- 宽度等于卡片内宽（390 宽屏幕上是 310），高 96，圆角 18。
- 嵌入感：`background: rgba(226,226,232,.78); border: .5px solid rgba(29,29,31,.08); box-shadow: inset 0 2px 6px rgba(29,29,31,.16), inset 0 1px 1px rgba(29,29,31,.08), 0 1px 0 rgba(255,255,255,.95)`。调谐窗要比卡片明显深一档，一眼能看出是嵌进去的。
- 比例：38.75px 对应 1 MHz，窗口宽度大约显示 8 MHz。频率范围 87.5–108。
- 刻度：每 0.2 MHz 一根，底部对齐在 y=52。整数 18px，半格 12px，其余 7px。偶数整数下方标数字（12px、细体、`--ink-3`）。
- 电台名在对应频率的正上方（y≈10），带电台色小圆点。当前电台用深色加粗，其余用 `--ink-3`。
- 两端各 48px 渐隐，颜色要和调谐窗底色一致。
- 指针：2px 宽、直播橙、固定在正中，上下各留 8px，外发光 `0 0 8px rgba(255,107,44,.55)`。

**拨轮**

- 高 26，圆角 13，纵向渐变模拟圆柱（上下暗、中间亮）。
- 竖纹按圆柱透视排布：31 条，角度在 ±70° 内均匀分布，`x = 中心 + R · sin(a) / sin(70°)`。线宽 1px，`rgba(29,29,31,.16)`。**相邻纹路间距不得小于 4px**，两端不能叠成粗线。
- 拨动拨轮时，纹路要跟着移动（相位变化），像真的在转。

**交互**

- 拖动调谐窗或拨轮都能调台。用 Pointer Events 自己实现跟手和惯性（速度衰减），比原生滚动更好控制吸附和中间状态。
- 松手后**总是**吸附到最近的电台。
- 距离最近电台超过 0.3 MHz 时进入“两个台之间”状态：
  - 调谐窗里出现噪点层，透明度随距离增大；
  - 信号格降到 1 格；
  - 台名变成灰色的“两个台之间”，描述变成“松手会自动对准最近的台”；
  - 光晕变成灰色；
  - 开播按钮禁用，文案“先对准一个台”。
- 进入某个电台 ±0.15 MHz 范围：信号格满格，台名淡入。安卓上调用 `navigator.vibrate(8)`（iOS 网页不支持，跳过）。
- 可选（P0 可以不做）：两台之间播放很轻的白噪声，默认关闭。
- 点击调谐窗里的电台名，直接滑到那个台。
- 键盘：左右方向键切到上一个、下一个电台。调谐窗是 `role="slider"`，`aria-valuetext` 例如“FM 97.4 人物志”。

**自由输入与自动匹配**

- P0 在前端用简单的关键词规则把输入匹配到电台，例如：
  - 包含“的故事”“这些年”“生平”“是谁”或明显是一个歌手名 → 人物志
  - 包含“怎么来的”“历史”“年代”“起源” → 来龙去脉
  - 包含“睡”“夜”“专注”“安静”“学习” → 夜里
  - 包含“像”“类似”“推荐”“没听过” → 唱片行
  - 其他 → 随便听
- 匹配后指针滑到该台，台名旁显示“按描述对准”。用户手动拨动后，这个标签消失，以用户选择为准。
- P1 后端会在方案里返回电台，届时改为用后端结果。

**时长**：分段控件“15 分钟 / 半小时 / 一小时”，对应现有 `duration_intent` 的 `SHORT / STANDARD / DEEP`，默认“半小时”。

**开播**

- 按钮文案“在 FM {频率} 开播”。
- 点击后：调用现有的节目方案接口，取第一个方案，**直接开始播放**（不再停在结果卡片、也不再经过详情页），同时进入“开播中”。
- 输入框为空时也可以开播，用该电台的默认主题（例如随便听：“随便放点好听的”；夜里：“睡前听的安静音乐”），文案可以先写在常量里。

### 6.2 开播中（`Frost-Tuning.dc.html`）

- 全屏页面，不是弹窗。左上角“取消”。
- 中间是同一个调谐窗（指针锁定在目标电台），下面是频率大字、台名、波形。
- 三步进度对应真实事件，不写装饰性文案：
  1. 方案接口返回 → “听懂了：{用户输入，或电台名}”
  2. 开场歌就位 → “开场歌就位：{歌手}《{歌名}》”
  3. 其余 → “正在排后面的曲目”
- 第一段音频可以播放时，自动转到播放页。
- 取消：回到调频页，忽略进行中的请求结果。
- 失败：在进度下方显示一句错误和“重试”按钮，不要静默失败。
- 底部固定文案：“音乐几秒内就会响起来，后面的内容边播边准备。”

### 6.3 播放页（`Frost-Player.dc.html`）

结构刻意贴近 Apple Music，用户不需要学习。

- **背景**：当前节目封面的无字版本，放大约 1.8 倍，`blur(70px) saturate(1.3)`，再叠一层深色（深色封面约 0.35，浅色封面约 0.55）。整档节目不变。
- **顶部**：拖动条；左边“收起”（下滑同样收起）；中间台标胶囊（橙点 + “FM 97.4” + 台名）；右边“更多”，打开操作抽屉（保存到节目库、导出 MP3、停止或恢复后台准备）。
- **封面**：310px，圆角 12，带投影。**整档节目固定，删除现在按章节变化封面的逻辑。**
- **歌名** 22/600，**歌手** 19/次要色。右侧“少放这类”按钮（拇指向下）。P0 没有接口，先本地记录并提示“会少放这类歌”。
- **主持字幕条**：当前片段是旁白时出现，显示旁白的展示文本（`text`，不是 `tts_text`）。字幕默认开启，底部“字幕”按钮可关。拿不到文本时，只显示声波和“主持在说”，不显示文字。
- **缓冲提示**：现在“剩余缓冲不足 45 秒”的提示保留，挪到字幕条的位置，显示一行“正在准备接下来的内容”。
- **进度条**：高 6，三层。已播是白色；已准备是白色 32% 透明；还在准备的部分是白色 22% 透明的虚线（3px 线、4px 间隔）。左边是已播时间，右边是“约 mm:ss”的预估总时长。**拖动不能超过已准备的位置**，超过时回弹，并轻提示“这部分还在准备”。

## 7. 封面系统

- 把 `TypeCover.dc.html` 移植到 `components/cover/`：一个纯函数 `buildCover(params)` 生成 SVG 图形数据，一个组件负责渲染。**同样的参数永远生成同样的封面。**
- 参数：`template, seed, bg, p1, p2, ink, heading, station, freq, bare`。
- 6 个模板：`column`（竖排）、`label`（唱片标签）、`freq`（频段）、`horizon`（地平线）、`contour`（等高线）、`split`（分割）。每个模板都是先确定标题的位置，再让图形为标题让路（例如等高线在标题区域自动断开），不要把标题当成后贴的一层。
- 电台默认模板：人物志 → `column`；唱片行 → `label`；随便听 → `freq` 或 `split`（由 seed 决定）；来龙去脉 → `contour`；夜里 → `horizon`。
- 色板：先用 `TypeCovers.dc.html` 里每个电台的那一组。`seed` 由节目 ID 哈希得到。
- 字号：按标题的“视觉宽度”计算（汉字算 1，拉丁字符算 0.56），用 `cqw` 单位，封面根元素设置 `container-type: inline-size`。各模板的字号公式在源文件里。
- **小于 64px 时用 `bare`**（不显示文字）：迷你条、节目库、播放页模糊背景。
- **标题来源**：优先用“封面短标题”（不超过 8 个汉字，允许一个换行）。P0 后端没有这个字段，前端规则：取标题里冒号或逗号之前的部分；如果视觉宽度仍然超过 10，这张封面不放标题（用 `bare`），标题显示在封面下方。
- **全局一致**：首页、播放页、迷你条、节目库、锁屏媒体信息都用同一组参数生成。
- 锁屏和控制中心的封面（MediaSession artwork）：把 SVG 画到 canvas 上导出 512 的 PNG。
- 删除旧的程序化封面组件，以及播放页里按章节换封面的逻辑。
