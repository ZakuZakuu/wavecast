# ADR 0038 — 「大家都在听」：首页的公开节目板块

状态：Accepted，2026-10-19（#327）。建立在 [ADR 0037](0037-published-programmes.md)（已发布节目、可见范围、听过记录）之上。

## 决定

- **内容**：发布时选了“所有人”（`PUBLIC`）且仍是 `PUBLISHED` 的整期节目。别人点开进节目详情（和打开分享链接一样），播放得到自己的副本，不生成、不占额度。撤回、改回“知道链接的人”、下架都会让它立刻离开（服务内状态变化会让排序缓存作废）。
- **排序**（`backend/wavecast/public_shelf.py`）：近 7 天里每位听众第一次播放算一次“被听”，半衰期 2 天；再加一份新鲜度（0.5 × 同样的衰减），这样还没人听过的新节目也能被找到。每个作者（账号，或未登录时的设备）最多 10 档在榜上（和每人同时分享的上限一样，现在基本等于不限；以后公开的人多了再收紧）。排好的前 60 档缓存 3 分钟。
- **对每个听众的过滤**：自己的、已经拿到副本的、下架的、本次已显示的都不出现；这些在取页时逐档判断，不影响缓存。作者自己点播放不计入“被听”，不给自己加热度。
- **接口**：`GET /api/public-shelf?shown=id,id`。一批 6 档，返回 `has_more`；第一页一档都没有时返回空（原先要求不足 3 档就整块隐藏，会让刚分享的节目看不见，已降为 1 档），客户端整块不显示。游客也能调用。不生成内容，所以没有每日上限。卡片只带 id、标题、封面短标题、电台、预计时长，不带作者、不带听众数。
- **封面**：已发布节目的封面由它自己的 id 生成，对所有人一致（首页、链接、节目库的听众副本）。分享链接因此不再带 `?c=` 封面提示。
- **界面**：首页“猜你想听”下面、电台上面，横滑；“换一批”按已显示的 id 翻页，加载时这一排变灰占位；翻完了“换一批”换成灰色“已经看完了”，这一排保留；接口失败也整块不显示。新手引导加一条 `home-public`（板块出现后才会讲）。

## 没做 / 限制

- 没有举报、没有人工策展；下架靠 `WAVECAST_TAKEN_DOWN_PROGRAMMES`。
- 缓存在 API 进程里；多实例时别的实例要等最多 3 分钟才看到撤回（撤回的节目点进去仍会被详情页的状态判断拦住）。
- “每个作者最多 10 档”按账号或设备计，游客后来登录会被算成两个作者。
- 榜单只按“被听”和新鲜度，不看口味，也不做“按你的偏好排序”。
