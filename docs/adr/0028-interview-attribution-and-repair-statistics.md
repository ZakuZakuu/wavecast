# ADR 0028: 本人采访的归属判断、保留已支持内容的修复提示、修复统计（离线）

- 状态：已实现并用固定文本、冻结证据和归档的真实样本离线验证；**没有新的付费调用**，不部署
- 日期：2026-10-15
- 前置：[ADR 0025](0025-story-material-and-checked-dialogue-path.md)（核对规则与修复）、[ADR 0027](0027-dialogue-runtime-wiring.md)

## 背景：一次真实验收

2026-10-15 的人物志单段验收（见 `tests/fixtures/dialogue_portrait_20261015/`）记录为：**人物志单段经过一次局部修复后通过，用户试听认可。**
首次核对没有通过：第 5、7 轮各有一句话因 `qualifier_not_in_quote` 被拦——“他还说过，自己没学过创作……”“他说过，希望自己的歌曲能够唤起大家关于爱的共鸣。”。两句话的事实都来自方大同本人的访谈回答，被拦的原因只是短引文里没有“说”字。修复随后把第 5 轮的第二句整句删掉（信息损失，**不追回重做**），第 7 轮改写后通过。

## 决定

### 一、“他说过”看来源的结构，不看短引文里有没有“说”

旧规则：句子里有“说过/曾说/自己说/坦言/他说……”时，支撑它的引文必须含“说/表示/述/言……”或引号。采访答语的短引文（“所以我希望自己的歌曲能够唤起大家爱的共鸣”）自然没有这个字，于是被误拦。

新规则只放宽这一个限定词（`self-said`），并且只在**来源本身能追溯这是本人答语**时：

1. `intelligence/attribution.py::own_words_of(来源全文, 引文, 人名, title=标题)` 在来源里定位引文（简繁、标点、空白不影响），然后要求：
   - 引文在一个**回答**里：它前面有提问标记（`▲……？`、`Q：`、`问：`、`记者：`），且二者之间没有别的提问；引文本身不能落在问题里；
   - 回答者**由来源指明**：要么紧挨着回答的发言人标签就是这个人（`方大同：……`；别人的标签、`歌手：`这类元数据行一律不算），要么没有标签时，标题把这个人放在受访者的位置（`Name专访`、`专访Name`、`……－Name`）。“某某谈 Name”、别人的专访、标题没点名、没有任何提问的文章或乐评**都不算**。
   - 不使用“句子里有‘我’”做任何判断。
2. 结果是 `MaterialFact.own_words_of`（可选，**只由代码在 `verify_material` 里写入，模型不能给**；此前保存的素材没有这个字段，读取不受影响，也保持旧的严格规则）。
3. 句子一侧：`says_only_what_the_speaker_said` 要求每个“说过”的主语是代词/“自己”（视为这位本人）或这位本人的名字；把“说过”给了别人（“周杰伦说过……”“乐评人说过……”）不算。
4. `qualifiers_missing(…, own_words_of=…)` 只对 `self-said` 采用上述结果；“第一次、一直、唯一、所有、所以、影响了、乐器、角色（作曲/作词/演唱……）、引文必须在来源里”等**其他事实规则一律不变**，仍要求引文自己携带。

### 二、修复提示：优先改写，保留已支持的内容

`DialogueRepairer` 的提示改为：优先改写有问题的那个说法（去掉素材没说过的限定、归属或评价，改成素材确实说过的表达）；这一轮里已经有素材支持的内容必须保留，不要为了通过核对而整句删除；只有某句话完全找不到依据、无法改写时才删那一句。仍然只改被标出的轮，说话人和轮数不变。
这次真实样本里第 5 轮的整句删除记为信息损失，不追回；提示变更没有经过真实模型验证（本批不做付费调用），只验证了提示文本和既有的修复应用逻辑。

### 三、统计：四个数分开记，样本不足时不下结论

`intelligence/dialogue_metrics.py`（流水线自动统计，`DialogueStack.metrics`；每个段落也输出一行日志）：

- **首次通过率** = 第一次核对就干净的段落 / 走到核对的段落；
- **修复触发率** = 进入修复的段落 / 走到核对的段落；
- **修复成功率** = 修复后通过的段落 / 进入修复的段落；
- **额外费用与耗时** = 修复调用 + 复核调用（费用取自带价格的用量事件，**任何一次调用没有价格则整体为未知**，不是 0；耗时是墙钟时间）；
- 另记**信息损失**（修复让被修轮少了几句）；写稿后在核对前就被拒（太长、无效）的段落按原因单独计数，**不进入任何比率**。

摘要同时给出样本量；少于 30 个走到核对的段落时 `rates_established=false`，仍给出计数，但不宣称比率成立。**本次的归档样本只有 1 个这样的段落**（首次未通过、触发修复、修复成功，额外 ¥0.0251、约 14 秒、损失 1 句；另有 1 个在随便听预算下写稿后被拒的草稿），不足以证明兜底低频，也不足以证明修复稳定有效。

### 四、回归样本

`tests/fixtures/dialogue_portrait_20261015/`：规范化素材、修复前后的稿件、两次核对结果、修复输出、三份安全用量摘要、冻结证据投影和 `MANIFEST.json`（每个文件的 sha256、验收状态、信息损失、尚未声称的内容）。试听音频（66.6 秒 WAV）不入库，位置和哈希在清单里。样本无凭据，也有测试检查。

## 仍未覆盖

- 真实模型是否会按新提示去改写而不是删句；以及它在真实核对里给出的引文是否总落在我们能追溯的回答里——需要下一次明确安排的真实调用。
- 来源结构的识别只覆盖 `▲……？`、`Q：/问：/记者：` 和 `Name：` 三种常见写法；其他版式保持旧的严格规则（宁可误拦，不冒认）。
- 额外费用只统计带价格的 Ark 调用；豆包配音没有价格，不在其中。
- 动态等待策略不在本批，等后续产品讨论。
